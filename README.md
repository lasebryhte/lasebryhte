## 🧑🏽‍💻 About Me

I'm a **4th-year Mechanical Engineering student at the University of Lagos (UNILAG)** exploring the intersection of **engineering, product design, electronics, software, and AI**.

I enjoy taking an idea from:

**💡 Concept → ⚙️ Design → 🔌 Electronics → 💻 Code → 🖨️ Prototype → 🧪 Test**

I'm currently learning by building projects, experimenting with different technologies, and documenting the process along the way.
